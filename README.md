整理版如下：

# RimeCapsShift

本程序在输入法为小狼毫 0.17.4 且处于中文模式时，将 CapsLock 的按下事件转为按住左 Shift：第一次按锁住左 Shift，第二次按松开左 Shift。  
CapsLock 的按下和抬起都不会透传给系统。小狼毫英文模式，或当前不是小狼毫时，CapsLock 行为保持系统原样。

## 为什么需要这个程序

小狼毫雾凇拼音下，按住 Shift 可以在候选框里打出大写字母——不直接上屏，也不清掉前面已经打的候选内容。这正是想要的效果。  
但我希望 `按下 CapsLock` 后也能得到和 `按住 Shift` 同样的行为。  
实际试下来，最接近的配置是：

```yaml
patch:
  ascii_composer/good_old_caps_lock: true
  ascii_composer/switch_key/Caps_Lock: noop
```

在这套配置下，CapsLock 确实不再直接触发上屏，看起来像“锁住了大写”。但 Rime 实际上把 CapsLock 这个键吃掉了：一旦开始键入大写字母，键盘上的 Escape、Backspace、Enter 就全部失效，只能继续键入或者选词。

这违背了我最初想要的效果，所以写了这个小程序：不去改 Rime 的配置，而是在系统层把中文模式下的 CapsLock 截下来，替换成“按住左 Shift”，让大写输入走 Shift 那条本来就没问题的路径。

## 程序默认适配的配置（可能需要自行修改）

因为拿不到小狼毫内部状态，程序的原理是通过监听特定键位来判断是否处于中英文状态。目前是监听 `Ctrl+Space` 和右 Shift。

我的 Rime 把**右 Shift**用作中英文切换，**左 Shift** 是 `noop`。该程序默认监听右 Shift、注入左 Shift——因为左 Shift 在我这里不触发切换。

如果你的切换键不同，要改 `--shift-key`，并保证注入的左 Shift 不会反过来触发切换，否则需自行上手改代码。

```yaml
patch:
  ascii_composer/switch_key/Shift_L: noop
  ascii_composer/switch_key/Shift_R: commit_code
```

## Python 版与 Go 版的现状

**Python 版**：`rime_caps_shift.py`，单文件，约 2500 行。便于 AI 修改。**Python 版不再改进**。  
但是 Python 版有一个缺点：小狼毫的后台服务占二十几 MB 内存，而 Python 版程序自身就能占用约 13 MB 内存。这个内存比例有些幽默。我就是因为有内存洁癖，才又改了 Go 程序；如果你也有，就要想清楚咯。

**Go 版**：如果凑巧你的键位配置和我相同，或者愿意接受我的键位配置，可以使用 Go 版；这个程序内存占用只有约 2–3 MB。

## 技术细节

### 小狼毫判断

小狼毫新版是 TSF 文本服务，前台窗口的键盘布局标识是通用的，看不出是谁。程序同时看两处：输入法的描述/文件名里有没有 `"Weasel"` / `"小狼毫"` / `"Rime"`，以及系统当前激活的文本服务是不是 Weasel。每 250 ms 查一次。

### 行为逻辑

- **中文模式下按 CapsLock**：第一次 → 锁住左 Shift（打字变大写）；第二次 → 解锁左 Shift。CapsLock 本身事件不会传给系统，系统的 Caps Lock 灯不会亮。
- **松开 CapsLock 的物理按键**：只吞掉抬起事件，不会解锁。锁存要再按一次 CapsLock 才解除。
- **短按被监听的 Shift**（默认右 Shift，阈值 500 ms）：切换中英文状态。Shift 本身照常传给 Rime。
- **Ctrl+Space**：照常交给 Rime，程序只同步自己的状态。按住物理 Shift 时跳过。
- **切到别的输入法**：自动释放 Shift、恢复托盘颜色、隐藏光晕。

“锁存大写”和“中英文状态”是两件独立的事：切到英文不会解掉 CapsLock 的锁，反之亦然。

### 视觉反馈

- **托盘图标**：没锁时是米白色，锁住时变琥珀色。
- **鼠标光晕**：锁住时鼠标周围出现一圈半透明呼吸光晕。再按 CapsLock 第二次或切走输入法就消失。光晕颜色和大小可以用 `--halo-color` / `--halo-size` 调，`--no-halo` 关掉。
- **提示音**：`--beep` 打开后，锁住和解锁各响一声。

### 已知限制

- **读不到 Rime 真实的中英文状态**。你用鼠标点 Rime 状态栏，或用程序没监听的快捷键切了中英文，程序不知道，会失步。短按一次被监听的 Shift，或按一次 Ctrl+Space，就能重新对上。
- 不能往管理员权限的窗口里注入按键。要用就先以同样权限启动本程序。
- UAC 弹窗、登录界面、锁屏这些安全桌面，钩子管不到。
- 部分游戏、反作弊、远程桌面会屏蔽低级键盘钩子，收不到映射。
- 独占全屏看不到光晕（托盘变色仍然有效）。
- 进程被强杀时 Shift 可能卡住。按一下物理 Shift 再松开就好，或者重新启动 / `--quit`。
